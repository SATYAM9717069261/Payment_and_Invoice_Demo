# AI Usage

I used AI as a helper during development to understand issues, fix setup problems, and improve testing and documentation. The main implementation and development process was done step by step.

## Where I used AI

### 1. Project Setup

* Used AI for guidance on setting up the Rust project structure.
* Took help with configuring the dependencies, PostgreSQL connection, and application structure.

### 2. Database Design and Migration Issues

* After designing the database tables, I faced some issues with setting up the migration files.
* Used AI to identify the problem and fix the migration setup.

### 3. Identifying Possible Loop Failures

* Used AI to review the code and identify possible cases where loops or control flow could fail.
* Used the suggestions to understand potential edge cases and improve the implementation.

### 4. Concurrent Payment Testing

* Used AI to help write test cases for concurrent payment requests.
* The goal was to check that multiple requests for the same invoice do not incorrectly start multiple payment attempts.

### 5. README Documentation

* Created a ZIP file of the project and shared it with ChatGPT.
* Used AI to help prepare the README with the project overview, setup steps, implemented features, API endpoints, and current limitations.

### 6. Docker Compose

* Used AI to create the Docker Compose configuration for running PostgreSQL during development.
* Used it to understand how Docker Compose differs from a Dockerfile.

## Overall

* I used AI mainly for guidance, debugging, test-case preparation, and documentation.
* I reviewed the suggestions in the context of the project and used them to understand the issues and move forward.
* AI assistance does not mean every suggested test or feature has been verified. The final implementation and test results should be checked before submission.
